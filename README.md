# 🌐 Meus Sites Favoritos

## 📌 Sobre o projeto

O objetivo do projeto consiste em desenvolver uma página web utilizando HTML para apresentar cinco sites favoritos. A página contém o nome de cada site, uma imagem representativa e um link para acessá-lo.

O projeto foi desenvolvido como parte de uma atividade prática de desenvolvimento web, com foco na utilização das principais tags HTML.
